## Things to watch for

- An agent attributes a message or idea to the wrong participant
- An agent loses earlier context in a long thread
- One participant's private documents or memory become visible to another agent
- Traces cannot be exported or linked to a specific message
- Uploads, links or connected accounts fail silently
